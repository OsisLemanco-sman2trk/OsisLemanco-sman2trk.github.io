# OSIS Lemanco – SMA Negeri 2 Tarakan

Situs statis OSIS: pengurus per periode, program kerja, kegiatan, pengumuman.

- Isi ada di `data/*.json`. Entri bertanda `"sample": true` adalah contoh dan menampilkan lencana "Contoh"; hapus sebelum dibagikan.
- Tampilan: `css/style.css`. Logika: `js/app.js`. Logo: `assets/`.
- Warna mengikuti logo; warna juga menandai jenis konten (merah pengumuman, kuning program, hijau kegiatan, biru pengurus).
